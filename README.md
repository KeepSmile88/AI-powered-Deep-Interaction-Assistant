## 🚀 安装方法

### 方式一：开发者模式安装

1. **下载插件文件**
   ```
   ai-interaction-plugin/
   ├── manifest.json
   ├── popup.html
   ├── popup.js
   ├── content.js
   ├── background.js
   ├── injected.js
   └── icons/ (需要添加图标文件)
   ```

2. **打开Chrome扩展管理页面**
   - 在Chrome地址栏输入: `chrome://extensions/`
   - 或者: 更多工具 → 扩展程序

3. **启用开发者模式**
   - 点击右上角的"开发者模式"开关

4. **加载插件**
   - 点击"加载已解压的扩展程序"
   - 选择插件文件夹

5. **确认安装**
   - 插件图标出现在工具栏中即表示安装成功

### 方式二：打包安装

1. 在开发者模式下点击"打包扩展程序"
2. 生成.crx文件
3. 拖拽.crx文件到扩展程序页面安装
